# 證據與來源規範

**ECD 研究標準 v0.1**

## 1. 目的

本規範確保研究主張可追溯、可檢查、可修訂，並避免將原始材料、學術解釋、假說及可視化模型混為一談。

## 2. 四層證據架構

### A 層：原始證據
包括手稿、碑銘、出土文書、考古遺物、同時代記錄及其他可識別原始材料。應保留收藏機構、編號、版本、圖版或穩定識別資訊。

### B 層：學術詮釋
包括校勘本、譯本、考古報告、年代研究、語言學分析及學術專著／論文。須標明作者、出版資訊及具體頁碼或章節。

### C 層：歷史假說
每項假說須列出：
- 主張內容及適用範圍；
- 支持證據及其層級；
- 反證與材料缺口；
- 競爭解釋；
- 信心水準及理由；
- 可使假說被修正或否證的新證據。

### D 層：綜合模型
包括時間軸、地圖、網絡圖、統計或文明動態模型。模型必須連結回 A、B、C 層來源，不得取代原始證據。

## 3. 主張標記

建議使用以下標記：
- **直接證據：** 來源直接記載或物質材料直接顯示。
- **間接證據：** 需透過多項材料或推理鏈支持。
- **學術推論：** 由研究者根據材料提出的解釋。
- **待驗假說：** 尚未獲得充分支持，仍需進一步檢驗。
- **未知／證據不足：** 現有材料無法判定。

## 4. 引用最低要求

每筆引用盡可能包含：
- 作者／編者、標題、出版或收藏機構；
- 出版年份、版本、卷冊；
- 頁碼、段落、行號、碑銘編號或檔案號；
- 原文語言與譯者；
- 穩定網址、DOI 或館藏識別碼（若有）；
- 存取日期（適用於可能變動的網頁資料）。

引用二手研究時，不得將其描述成直接檢視過原始材料，除非確實如此。

## 5. 文本與資料保存

- 保留原文、轉寫、譯文與編者補字之間的區別。
- 殘缺字、推補字、異讀及爭議年代須明確標記。
- 不得為了讓敘事連貫而靜默修補原始材料。
- 修訂資料時保留舊版本或版本紀錄。
- 不得將未經授權的整本書籍、論文或資料庫複製進倉庫。

## 6. 推論禁區與常見錯誤

- 時間先後不等於因果。
- 名稱相似不等於族群同一。
- 同時存在不等於直接接觸。
- 文化相似不必然代表單向傳播。
- 網絡延續不等於制度毫無中斷。
- 未見史料不等於事件不存在。
- 模型輸出的連線不等於歷史上已證實的關係。

## 7. 不確定性與爭議處理

有爭議的年代、地名、族名、文本讀法或路線，應並列主要學術觀點，說明各自依據。若無法判定，保留多種假說，不以多數投票代替證據判斷。

## 8. 資料更正

任何更正應附上：
1. 原紀錄與修訂內容；
2. 修訂理由；
3. 新增或更正的來源；
4. 對相關假說、圖表或模型的影響；
5. 修訂者與日期。

## 9. 版權與使用

引用、連結與書目資訊不代表原始作品可自由再散布。貢獻者須確認文本、圖片、地圖及資料集的授權條件。未確定授權時，優先提供書目資訊、短摘錄（符合法律與授權限制）及來源連結。
