# 去中心化自組織網絡（DSON）

**英文名稱：** Decentralized Self-Organizing Networks  
**狀態：** ECD 初步分析假說 v0.1；非既定歷史定律

## 1. 核心假說

文明的延續與轉型，可能不只取決於帝國中心的穩定，也受到跨區域網絡的連結、資訊與資源流動、信任規範、適應及重組能力影響。

本假說要求研究者檢驗：在政治中心變動時，不同類型的網絡是否仍能維持部分功能？若能，依靠哪些節點、關係與制度？若不能，何種因素造成中斷？

## 2. 概念界定

- **去中心化：** 網絡不完全由單一中心控制；不代表沒有樞紐或權力不平等。
- **自組織：** 行動者透過重複互動、地方規範與分散決策形成可觀察的協作模式；不意味著沒有制度。
- **網絡：** 由可識別節點及其關係構成。節點可以是個人、家庭、城市、社群、機構或交通據點。
- **韌性：** 網絡在衝擊後維持、恢復或調整特定功能的能力；必須指出具體功能與觀察證據。

## 3. 六項初步分析變項

| 代碼 | 變項 | 研究觀察 |
|---|---|---|
| N | 節點自主性 | 節點能否在中心失效或權力更替時獨立運作 |
| C | 連通性與冗餘 | 是否存在多條路徑、替代節點及跨區域連結 |
| T | 信任與規範 | 是否有共同規則、聲譽機制、承諾與互惠 |
| F | 流動 | 人員、商品、資訊、資金與知識如何移動 |
| R | 韌性 | 衝擊後哪些功能得以維持、恢復或消失 |
| A | 適應與重組 | 網絡是否改變路徑、節點、規則或組織形式 |

這些變項是研究工具，不應在缺乏材料時量化成看似精確的分數。

## 4. 主要網絡類型

1. **商業網絡：** 商人家族、商隊、城市、港口、市場與信用關係。
2. **宗教網絡：** 傳教者、地方社群、教會、主教、修道院、文本與禮儀。
3. **遷徙網絡：** 人口移動、親族關係、政治聯盟、定居與人口混合。
4. **知識／資訊網絡：** 文書、翻譯、學術傳承、技術與消息傳遞；可作為跨領域層次分析。

不同網絡可能重疊，但重疊必須由具體史料支持，不能僅因同處一地或同一時代便推定。

## 5. 可比較的歷史結果

研究至少應區分以下結果：
- **延續：** 主要功能與關係在衝擊後仍可辨識。
- **部分延續：** 部分節點或功能保留，其他部分消失。
- **遷移：** 網絡重心或路徑轉移至其他區域。
- **重組：** 節點、規則、身份或組織形式發生變化。
- **斷裂：** 關鍵功能或可辨識關係不再延續。
- **證據不足：** 現存材料不足以判定。

「證據不足」不得被強行歸入延續或斷裂。

## 6. 研究設計與可反駁性

對每個案例：
1. 指定網絡、時間窗、區域及所謂「衝擊」。
2. 確定衝擊前後可觀察的節點、關係與功能。
3. 記錄資料來源及保存偏差。
4. 比較中心控制、地方自主、冗餘路徑、信任制度等因素。
5. 提出至少一個競爭解釋。
6. 說明什麼證據會削弱或推翻目前假說。

若網絡在中心崩解後同樣迅速瓦解，或其延續完全依賴另一個強勢中心，便可能削弱特定案例中的 DSON 解釋。

## 7. 重要限制

- 去中心化網絡不必然比集中式制度更有效或更穩定。
- 高連通性可能增加傳播速度，也可能加速危機擴散。
- 樞紐能提升效率，也可能形成單點失效。
- 網絡的可見度受史料保存、書寫群體與考古發掘偏差影響。
- 名稱、宗教符號或物質文化相似，不足以單獨證明網絡連結。
- 不能把現代網絡科學術語不加轉換地投射到古代社會。

## 8. 與 TCHS 的關係

TCHS 提供比較的時間切片與多尺度觀察架構；DSON 提供一組待驗證的網絡解釋變項。任何 DSON 結論都必須回到 TCHS 切片中的具體人物、地點、事件與來源。
