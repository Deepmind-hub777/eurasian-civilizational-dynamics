# 跨文明歷史切片法（TCHS）

**英文名稱：** Trans-Civilizational Historical Slicing  
**狀態：** ECD 工作方法 v0.1；供案例測試與修訂

## 1. 定義

跨文明歷史切片法（TCHS）是一種比較研究設計：在明確界定的時間窗內，將不同文明區域放入共同年代座標，並從多個歷史維度與尺度觀察其同步發展、互動及差異。

它不是把文明視為封閉、同質的整體，也不是以單一帝國年表替代各地自身的年代系統。

## 2. 三個維度

### 2.1 同時性（Synchronicity）

- 明確標示事件的年代、年代範圍及年代判定依據。
- 區分事件發生時間、文獻記錄時間、文本編纂時間與後世追述時間。
- 對不同曆法、紀年、曆法換算與年代爭議保留說明。
- 同時發生只代表時間上的並存，不足以證明因果或直接接觸。

### 2.2 多維性（Multidimensionality）

每個切片可依材料涵蓋程度考察：
- 政治與軍事
- 人口、遷徙與族群互動
- 商業、農業、財政與交通
- 宗教、思想與教育
- 科技、工藝與知識傳播
- 環境、氣候與疾病
- 法律、制度與社會組織

不要求每個案例填滿所有維度；資料缺失須明確標記。

### 2.3 多尺度（Multi-scalar Analysis）

在以下尺度之間切換：
- 個人與家庭
- 聚落、城市與地方社群
- 商業、宗教、移民及知識網絡
- 王國、帝國與跨區域政治體系

宏觀模型必須能回到具體人物、地點、文本或考古材料接受檢驗。

## 3. 切片工作流程

1. **界定問題：** 說明要解釋的歷史現象，不先預設答案。
2. **設定時間窗：** 指定單一年份、短期區間或世紀範圍，並說明理由。
3. **設定空間範圍：** 說明納入哪些區域，以及排除哪些區域。
4. **建立同步表：** 列出各地事件、年代依據與不確定性。
5. **分維度整理：** 依政治、人口、經濟、信仰、技術等分類。
6. **辨識行動者與網絡：** 記錄人物、機構、城市、路徑及可證實的連結。
7. **提出比較：** 說明相似、差異、可能互動及尚未證實的關係。
8. **檢查反證：** 尋找替代解釋、年代衝突及材料偏差。
9. **連接相鄰切片：** 追蹤變化，不把單一截面誤當完整歷史。

## 4. 最低輸出欄位

| 欄位 | 說明 |
|---|---|
| Slice ID | 唯一切片編號 |
| Research question | 核心問題 |
| Time window | 時間窗及年代依據 |
| Regions | 涵蓋區域 |
| Dimensions | 使用的歷史維度 |
| Actors and nodes | 人物、群體、城市、機構 |
| Events and relations | 事件與有證據支持的關係 |
| Evidence references | 對應來源與位置 |
| Uncertainties | 不確定性與材料缺口 |
| Alternative explanations | 競爭解釋 |
| Revision history | 修訂紀錄 |

## 5. 常見錯誤

- 將不同地區的紀年直接換算，卻不交代換算依據。
- 把後世文獻的敘述當成事件同時代記錄。
- 把同時存在誤認為直接接觸。
- 把相似文化現象直接解釋為單向傳播。
- 以現代民族或國界概念套用古代社會。
- 只挑選支持既有假說的材料，忽略反證。

## 6. 方法限制

TCHS 是研究設計方法，不會自動產生因果解釋。因果主張仍須透過具體機制、時間順序、來源品質、替代解釋及反證檢驗。切片結果也受史料保存不均、語言能力及研究者選樣影響。

## 7. 與 DSON 的關係

TCHS 用來建立可比較的歷史切片；DSON 則可作為分析切片中網絡結構與變遷的假說框架。兩者不可混為一談：方法負責如何觀察，假說負責提出可檢驗的解釋。
