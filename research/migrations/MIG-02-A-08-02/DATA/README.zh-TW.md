# MIG-02-A-08-02-DATA｜永嘉南渡人口遷徙可審計資料庫

版本：0.1.0  
研究窗口：約 280–450 CE；核心觀察期約 307–317 CE。

## 目的
將遷徙事件、人物／群體、地點、史料、證據關係與研究判斷分開保存，使每項歷史主張可追溯、可複核、可修訂。

## 檔案
- `schema.sql`：SQLite 資料庫結構。
- `event-import-template.csv`：遷徙事件與證據關係匯入模板。
- 對話工作區另提供已初始化的 SQLite 資料庫檔，含地點索引、書目入口與待驗主張。

## 核心資料表
- `migration_events`：遷徙事件。
- `actors_groups`：人物、家族及群體。
- `places`：歷史地點及現代定位。
- `sources`：史料與研究文獻。
- `evidence_links`：事件與證據的逐條連結。
- `claims`：歷史判斷、解釋、假說與模型。
- `event_actor_links`、`event_place_links`：多對多關聯。
- `audit_log`：修訂理由與變更紀錄。

## 證據類型與記錄狀態分開
證據類型：A 原始史料／碑刻／墓誌／考古；B 現代學術研究；C 推論／假說；D 綜合模型。  
記錄狀態：`verified`、`provisional`、`disputed`、`unverified`、`rejected`。

A 不代表自動正確；B 不得冒充原始史料。

## 錄入規範
1. 年代相近不等於因果關係。
2. 侨置政區不自動等於移民實際居住地。
3. 家族後來出現在江南，不自動證明其遷徙時間與路線。
4. 每條遷徙事件必須關聯可定位證據；沒有證據時只登記為 claim 或待查線索。
5. 數量估算須記錄統計口徑、時間範圍、分母、推算方法及不確定性。
6. 原文、卷次、版本、頁碼／條目定位盡可能精確。
7. 支持、反證與異說分別登記，不覆蓋舊紀錄。
8. 地名須區分歷史轄境、城址、侨置行政區與現代地理定位。

## 初始狀態
目前已建立資料結構與書目入口。**尚未將任何具體遷徙事件標記為 verified。**這是刻意的品質控制，不是漏錄。
