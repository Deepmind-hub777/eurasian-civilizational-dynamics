# ECD-HYP-01｜歷史網絡的可見性偏差

**English title:** Historical Network Visibility Bias  
**系列：** ECD Hypothesis Register  
**版本：** v0.1 — 初始研究框架  
**狀態：** 待檢驗假說（Working Hypothesis）  
**研究範圍：** 古代歐亞跨區域網絡；首輪案例為敦煌、吐魯番、和田與穆格山  
**關聯研究：** ECD-COLLECT-01、ECD-313、TCHS、DSON

---

## 1. 核心問題

我們今天能夠觀察到的古代文明網絡，有多少反映歷史活動本身，又有多少是由文獻與物質材料的保存、考古發現、現代收藏制度、學術辨識、刊布及數字化條件共同塑造？

本研究不預設古代網絡必然比現存材料所呈現的範圍更廣，也不預設所有缺失材料都曾經存在。它要檢驗的是：**歷史活動的分布與現代證據的可見性分布，是否存在可辨識、可比較的系統性偏差。**

## 2. 工作假說

**H1：** 對古代跨區域網絡的現代認識，受到一連串材料存續與知識生產環節的選擇效應影響；因此，現存文獻、博物館收藏及數字資料庫的地理分布，不能直接等同於古代人口、商業、宗教或資訊網絡的實際分布。

**H2：** 不同地區、材料類型、語言及保存環境所受的選擇效應並不相同；因此，單純比較各地現存文獻數量，可能造成對歷史網絡中心性、密度與連續性的錯誤判斷。

這兩項是待檢驗主張，不是已確立的歷史定律。

## 3. 概念邊界

本研究區分四種地理位置：

1. **出土地（findspot）：** 文物或文獻被考古發現的位置。
2. **製作／書寫地（production or writing place）：** 材料實際製作或書寫的位置；若無直接證據，標記為未知或推定。
3. **收藏地（repository）：** 材料目前保存的機構或收藏地。
4. **文本所述地（mentioned place）：** 文本中提及的人物、地點、事件或目的地。

四者不可互相替代。尤其不能把收藏地當成古代網絡節點，也不能把文本提及地直接當成作者曾經到訪的地點。

另須區分：

- **語言**與**出土地區**：在和田發現的粟特語文書，不等於和田語文獻；粟特語與和田語不可混為一類。
- **數字化**與**完整刊布**：有影像不代表已有可靠釋讀、翻譯、定年與完整目錄。
- **材料缺失**與**歷史活動不存在**：未發現證據不等於證明沒有活動。
- **網絡存在**與**網絡連續**：不同時期材料分布相近，不足以證明同一制度或社群從未中斷。

## 4. 可見性形成鏈

研究把今日可觀察到的材料視為經過多個環節篩選的結果：

**歷史活動 → 材料生成 → 保存／損毀 → 再利用或埋藏 → 考古發現 → 收藏與流散 → 語言／年代辨識 → 編目與刊布 → 數字化與檢索**

每一環節都可能造成不同形式的偏差：

| 環節 | 可能的可見性偏差 | 可查證問題 |
|---|---|---|
| 材料生成 | 某些活動本來就較少留下書面記錄 | 哪些活動使用文書？哪些主要依靠口述或易腐材料？ |
| 保存／損毀 | 氣候、材質、埋藏環境與戰亂影響存續 | 不同材料在不同環境中的存續條件為何？ |
| 再利用／埋藏 | 文書可能被回收、改寫、建築性再利用或集中封存 | 材料如何進入遺址或封閉空間？ |
| 考古發現 | 發掘範圍、方法、年代與研究者興趣影響發現 | 哪些地區尚未充分調查？ |
| 收藏與流散 | 探險、殖民史、交易與機構政策影響現藏地 | 出土材料如何流入不同國家與機構？ |
| 辨識與編目 | 語言知識、分類方式及目錄品質影響材料是否可被找到 | 是否存在未辨識、誤分類或描述不足的材料？ |
| 刊布 | 編輯資源、學術議程及出版條件影響研究可及性 | 已辨識材料中有多少尚未完整刊布？ |
| 數字化 | 經費、版權、影像品質與平台政策影響線上可見性 | 哪些材料有影像、可檢索文字或可下載資料？ |

這是一個分析框架；各案例必須以具體材料驗證，不能預先假定每個環節都造成同等程度的偏差。

## 5. 首輪比較案例

### 5.1 敦煌

- 粟特古信札（Ancient Letters）與莫高窟第17窟文書，必須按年代、文書類型及出土情境分開處理。
- 英國、法國等地收藏的敦煌材料，說明出土地與現藏地可能分離。
- 不可將四世紀古信札、主要屬八世紀及以後的第17窟粟特語材料，以及晚期商業文書合併成一個未分期的「敦煌粟特網絡」。

**待查：** 各件材料的出土紀錄、原始編號、現藏機構、語言、年代、刊布狀態及數字影像狀態。

### 5.2 吐魯番

- 德國吐魯番考察所得材料分散於不同收藏機構；柏林吐魯番收藏是重要收藏群，但不能代表所有吐魯番材料。
- 大英圖書館 Or.8212 系列中亦有標示來自吐魯番不同地點的材料。
- 「吐魯番收藏」不是單一語言或單一宗教文本集合。

**待查：** 各館藏品的具體出土地、語言與文本分類；區分已數字化、已刊布及僅有目錄紀錄的材料。

### 5.3 和田

- 必須區分粟特語文書與和田語（Khotanese）文獻。
- 麻札塔格（Mazar Tagh）等地出土的粟特語材料，現藏地分布涉及不同機構。
- 和田語材料可作為同一地區的比較語料，但不得計入粟特語文書數量。

**待查：** 各件文書的語言判定、出土點、收藏機構、文本類型與研究版本；核對已出版的和田粟特語經濟文書、書信及零散文書。

### 5.4 穆格山

- 穆格山粟特文書的核心收藏與俄羅斯科學院東方文獻研究所有關。
- 阿弗拉西阿卜博物館等其他收藏線索，以及塔吉克斯坦檔案中曾被記錄但現況不明的材料，應分別標記其證據狀態。
- 穆格山材料與敦煌、吐魯番、和田材料在文書類型、政治情境及保存方式上不同，不可只按件數直接比較。

**待查：** 各件材料的原始編號、出土情境、現藏狀態、影像可及性及刊布版本；對「失佚」或「下落不明」的記錄保留來源與日期。

## 6. 資料記錄規格

每件材料原則上建立一筆紀錄；若同一件材料有正反面、殘片拼合或多個影像資源，使用子紀錄連結，不重複計件。

建議欄位：

| 欄位 | 說明 |
|---|---|
| record_id | ECD 內部唯一識別碼 |
| object_id | 收藏機構原始編號 |
| site | 考古遺址或出土地區 |
| findspot_precision | 出土地位置精確度及其來源 |
| repository | 現藏機構 |
| language | 語言；未知時明確標示 |
| script | 書寫系統 |
| material | 紙、木、皮革、石、金屬等 |
| document_type | 信件、帳目、契約、宗教文本等 |
| date_range | 年代範圍 |
| dating_basis | 年代依據及相關爭議 |
| production_place | 書寫／製作地及證據狀態 |
| mentioned_places | 文本提及地點，逐項記錄 |
| publication_status | 未刊布／初步刊布／完整校訂等 |
| digitization_status | 無影像／有影像／可檢索文字等 |
| identification_status | 已確認／暫定／待辨識 |
| source_refs | 目錄、出版物、影像與研究來源 |
| confidence | 各項判斷的信心水準 |
| notes | 缺損、拼合、異讀、收藏史及其他限制 |

**狀態欄位不得混用。** 例如「已數字化」不代表「已完整釋讀」；「已辨識」不代表「定年無爭議」。

## 7. 研究指標與比較方法

首輪不急於建立單一「網絡密度分數」。先建立可審計的分項指標：

1. **目錄可見度：** 已知材料中，有多少具有可公開查詢的機構目錄紀錄？
2. **影像可見度：** 有多少材料具有可存取的數字影像？
3. **文本可讀度：** 有多少材料具有可靠的釋讀、轉寫或翻譯？
4. **年代確定度：** 有多少材料具有可追溯的定年依據？
5. **來源透明度：** 出土地、流散與收藏史有多少可由來源記錄核實？
6. **分類穩定度：** 語言、文書類型及宗教歸屬是否存在爭議或修訂？

所有比例必須先說明分母。例如「已數字化比例」只能以一個定義清楚、範圍明確的材料清單為分母，不能以未經界定的「全部古代粟特文書」為分母。

地理比較至少製作三張互不替代的圖：

- 出土地圖；
- 現藏機構分布圖；
- 文本所述地點／可證實聯繫圖。

若要推論歷史網絡，必須另外列出每條連線的證據種類、年代、方向與信心水準。不得由兩地各有文書就直接畫出兩地之間的聯繫。

## 8. 反證、競爭解釋與否證條件

本假說不能成為「凡是看不見的網絡都一定存在」的萬用解釋。以下觀察會削弱或限制它：

- 在保存條件、考古調查強度、材料類型與出版程度相近的案例中，現存材料分布仍穩定而一致地反映獨立證據所重建的歷史活動分布。
- 某些看似「缺失」的地區，經系統調查後仍沒有任何相關材料，而且沒有其他獨立證據支持該地存在相應活動。
- 收藏與數字化差異對某些研究問題影響甚微，不能解釋觀察到的網絡分布差異。
- 原先被視為未辨識或未刊布的材料，經核查其實不屬於研究對象。

競爭解釋包括：

- 古代活動本身確實高度集中；
- 不同社群的文書使用率與行政制度不同；
- 文書類型不同，留下來的機率也不同；
- 某些材料的地理集中是考古埋藏或特殊事件造成，而非日常網絡中心性。

若資料不足以區分這些解釋，結論應維持「未能判定」，不可強行支持 H1 或 H2。

## 9. 與 TCHS、DSON 的關係

- **TCHS：** 提供同時性、多維度、多尺度的比較座標；避免把不同年代與不同材料類型混為一談。
- **DSON：** 可作為後續分析網絡節點、連通、信任、流動與韌性的假說框架；但 ECD-HYP-01 只處理「我們如何看見網絡」的認識論與資料偏差問題。
- 本假說不證明粟特社會必然是去中心化網絡，也不證明網絡比帝國制度更具韌性。
- 網絡模型不得覆蓋或改寫原始材料的內容與限制。

## 11. 下一階段工作

1. 把 ECD-COLLECT-01 的樣本清單轉為逐件資料表，補上每件材料的來源與狀態欄位。
2. 優先核對敦煌粟特文書的原始館藏編號、出土地與刊布狀態。
3. 建立吐魯番材料的跨館藏對照表，避免把整個柏林收藏誤算為粟特語材料。
4. 將和田粟特語與和田語材料分成兩個語料集合。
5. 核查穆格山文書的現藏、失佚及影像紀錄。
6. 在樣本範圍與分母穩定後，再比較各地的目錄、影像、釋讀與來源透明度。

## 12. 暫定結論

目前可支持的結論是：**古代活動的地理分布與今日可見材料的地理分布，必須作為兩個不同的研究對象。** 四地跨國收藏與數字檔案的初步清查，已顯示出土地、現藏地、語言與數字可及性不能混為一談。

但目前樣本尚不足以量化偏差幅度，也不足以重建粟特網絡的完整規模。ECD-HYP-01 因此維持「待檢驗假說」，等待逐件材料清單與可比較的資料分母建立後再作判斷。

---

**研究紀律：** 不把缺失當成不存在，不把推定當成事實，不把數字化程度當成歷史重要性，也不讓宏觀網絡圖取代單件材料的證據。
