# 假說登錄｜Hypothesis Register

本目錄只收錄明確標示、可由證據檢驗及修訂的歷史假說。

每項假說至少記錄：
- 假說 ID、版本與提出日期；
- 精確主張及適用範圍；
- 支持材料與來源位置；
- 反證、資料缺口與競爭解釋；
- 信心水準及其理由；
- 可使假說被修正或否證的觀察；
- 修訂歷史。

不得因假說被多位貢獻者接受，就將其自動升格為史實。
