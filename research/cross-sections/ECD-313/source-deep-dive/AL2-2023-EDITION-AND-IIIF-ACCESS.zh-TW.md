## 2. 斷代爭議：關鍵不只在日期，也在第14行重建

目前應把斷代證據分成三層：

| 層級 | 來源與主張 | 研究處理 |
|---|---|---|
| 館藏編目 | IDP：313–314 CE | 目錄日期，不等於精確寫作日 |
| 專家對信件內證的判斷 | Sims-Williams介紹：可能寫於313年6／7月；Smithsonian列312或313年 | 作為主流工作日期，仍保留區間 |
| 早期學術爭議 | Henning提出312年，較傾向313年；Harmatta提出190–195年；Fujieda依紙張分析提出六世紀可能 | 必須交代各說的文本前提與證據強弱，不可只列年代而不列論證 |

Nicholas Sims-Williams在《Encyclopaedia Iranica》“Ancient Letters”條目中特別指出：

1. 第二封信第10–19行提到皇帝據說因中國人與Huns（粟特語xwn）之間的戰事而離開洛陽，以及洛陽、鄴遭破壞。
2. Henning將其與307年鄴城陷落、311年洛陽陷落及皇帝試圖出逃相聯繫，據此把信件定在312–313年。
3. Harmatta提出190–195年的替代解釋；其論證關鍵依賴第14行的文本重建。
4. Sims-Williams指出，Harmatta對關鍵第14行的讀法建立在文本重建之上；Henning自己的替代解釋也涉及重建。因此，不能把第14行當作完全透明、無爭議的文字。

這帶來一個重要的校勘原則：

**第14行的字形、補讀、句法與地名辨識，可能同時影響族名解讀與整封信的斷代。**

因此，不應先把年代定為313年，再用313年的歷史事件反過來證明第14行必須如此讀；也不應先假定xwn必定是某一固定族群，再以此排除其他斷代方案。兩者需要交叉檢驗，並保留循環論證風險。

## 3. 目前可以確認與不能確認的事

### 可以確認

- 原件是British Library Or.8212/95，館藏頁與IIIF manifest均可查。
- 2023年CII新編本確實將Ancient Letters列為第2節，起於印刷頁碼25；Grenet歷史討論起於第63頁。
- IDP目錄給出313–314年；Sims-Williams的介紹則以可能的313年6／7月為工作日期。
- 斷代爭議與第14行重建、xwn的讀法和事件辨識有關。
- 原件影像有正反面及拼接視圖，為後續校勘提供了可追溯的影像入口。

### 尚不能確認

- 2023年版第10–19行相較2001年版是否改動了任何字母、補讀、標點或翻譯。
- 第14行原件上每個字母的可辨程度。
- 2023年Grenet歷史討論是否對Henning／Harmatta爭議提出新的決定性論證。
- 影像中某一筆畫是否足以支持特定的字母辨識。
- 是否存在能獨立於第14行重建、支持313年定年的外部紀年證據。

## 4. 下一輪逐行校勘工作表

後續應為第10–19行逐行建立以下欄位：

| 欄位 | 必須記錄的內容 |
|---|---|
| Line | 原件行號 |
| Image locator | IIIF manifest、canvas與影像區域 |
| Visible graphemes | 原件可見字形；看不清楚就標記不確定 |
| 2001 reading | Sims-Williams 2001版轉寫 |
| 2023 reading | CII 2023版轉寫；尚未取得就標記待核 |
| Editorial intervention | 補字、復原、刪補、問號與編者標記 |
| Translation | 專家英譯；不可自行把工作性中文轉述冒充直譯 |
| Historical referent | 可能對應的歷史事件與競爭性解釋 |
| Confidence | 高／中／低，並寫明判斷理由 |

優先順序：

1. 第14行：直接關係到xwn及早期斷代爭議。
2. 第10–11行：皇帝離開洛陽、饑荒與轉述語氣。
3. 第12–13行：洛陽、鄴的地名與「不復存在」表述。
4. 第15–16行：長安、鄴及「昨日仍為皇帝臣民」的句法關係。
5. 第17–18行：作者明言未知的範圍與地理指涉。
6. 第19行：撒馬爾罕自由民及商業社群資訊。

## 5. 本輪暫定結論

這一輪真正增加的不是一個新的歷史定論，而是把下一步校勘變成可操作、可追溯的工作：

- 我們已找到原件正反面及拼接影像的IIIF資源結構。
- 我們已定位2023年權威新編本的正文與歷史討論頁碼。
- 我們確認第14行重建與整封信的斷代爭議彼此牽連。
- 我們也明確記錄：目前還沒有逐字讀完2023年版，也沒有從原件影像辨認第14行。

**核心方法約束：**在原件影像、2001年版、2023年版三者尚未逐行對照前，所有新讀法只能標記為待驗假說；不得以歷史敘事的順暢程度代替字形證據。
